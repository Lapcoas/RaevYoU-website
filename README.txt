RaevYoU website — GitHub Pages

Files:
- index.html
- style.css
- script.js
- assets/avatar.jpg

Publish:
1. Create a GitHub repository.
2. Upload all files and the assets folder, preserving the structure.
3. Open Settings → Pages.
4. Select Deploy from a branch, choose main and / (root), then Save.

The language and theme choices are saved in the visitor's browser.
Edit the text, links, and prices in index.html / script.js as needed.
